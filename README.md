## 🚀 Быстрый запуск

### Требования
- Docker и Docker Compose
- Или Java 17 + Maven 3.9 (для локального запуска)

### Локально (без Docker)

```bash
# Требования: Java 17 + Maven 3.9
mvn spring-boot:run
```
Приложение будет доступно по адресу: http://localhost:8090

### Запуск через Docker Compose (рекомендуется)

```bash
# Сборка и запуск контейнеров
docker compose up -d --build

# Проверка статуса
docker compose ps

# Просмотр логов приложения
docker compose logs -f todo-app

# Остановка
docker compose down
```

## ☁️ Автоматический деплой (CI/CD)

Проект использует два пайплайна на основе GitHub Actions:
- 🔄 pr-check.yml — Проверка пулл-реквестов
- Запускается автоматически при создании или обновлении пулл-реквеста в ветку master:
- ✅ Собирает проект через Maven
- ✅ Запускает тесты с временной БД PostgreSQL
- ✅ Создаёт артефакт (JAR-файл)
- Результат: Если тесты проходят — пулл-реквест можно мержить.
- 🚀 deploy.yml — Деплой в продакшен
- Запускается автоматически при пуше кода в ветку master:
- ✅ Собирает проект через Maven (без тестов)
- ✅ Собирает оптимизированный Docker-образ
- ✅ Отправляет образ в Docker Hub (mngerasimenko/todo-app)
- ✅ Подключается к серверу по SSH
- ✅ Запускает/перезапускает контейнер с БД PostgreSQL
- ✅ Скачивает новый образ и перезапускает контейнер todo-app
- Результат: Приложение автоматически обновляется на сервере.

## 🔧 Первоначальная настройка сервера (для администраторов)

Для развёртывания на **чистом сервере** (Ubuntu/Debian) выполните один раз:


# 1. Склонируйте репозиторий
```bash
git clone https://github.com/mngerasimenko/ваш-репозиторий.git
cd ваш-репозиторий
```
# 2. Запустите инициализационный скрипт (требуются права root)
```bash
chmod +x setup-server.sh
./setup-server.sh
```
Скрипт автоматически:
- ✅ Устанавливает системные обновления и сертификаты
- ✅ Устанавливает Docker
- ✅ Создаст сеть todo-network
- ✅ Запускает контейнер с PostgreSQL 17
- ✅ Дождётся готовности БД
- ⚠️ Важно: Скрипт нужно запускать ТОЛЬКО ОДИН РАЗ при подготовке нового сервера.
  - Данные БД сохраняются в именованном томе postgres-data
  - Дальнейшие деплои выполняются автоматически через git push origin master
